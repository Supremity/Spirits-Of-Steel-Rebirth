# Important Figure Skills Reference

| Name                       |        Type        | Usage                                                       |
| :------------------------- | :----------------: | :---------------------------------------------------------- |
| `stability`                |    **additive**    | Flat stability bonus                                        |
| `warSupport`               |    **additive**    | Flat war support bonus                                      |
| `dailyPPGain`              |    **additive**    | Flat Political Power gained per day bonus, applied last     |
| `divCostMod`               | **multiplicative** | Cost of division upkeep modifier                            |
| `troopSpeed`               |    **additive**    | Flat troop speed bonus                                      |
| `troopAttackAdd`           |    **additive**    | Flat troop attack power bonus, applied before the modifier  |
| `troopAttackMod`           | **multiplicative** | Troop attack power modifier, applied last                   |
| `troopDefendAdd`           |    **additive**    | Flat troop defense power bonus, applied before the modifier |
| `troopDefendMod`           | **multiplicative** | Troop defense power modifier, applied last                  |
| `attackerAttackMitigation` | **multiplicative** | Damage taken when defending modifier, applied last          |
| `defenderAttackMitigation` | **multiplicative** | Damage taken when attacking modifier, applied last          |
